# Проект получения информации о вакансиях с платформы hh.ru в России:
Приложение для получения, фильтрации и сортировки вакансий, записи результатов в файл

## В проекте реализованы функции:
* в модуле api_get_vacancies реализован класс HeadHunterAPI, который получает 
  список вакансий с платформы HeadHunter по заданному ключу(слову)
* в модуле json_saver реализован класс для добавления данных о вакансиях в файл,
  получения данных из файла и удаления информации о вакансиях
* в модуле utils реализованы функции сортировки и фильтрации списка вакансий:
  - фильтрации из всех вакансий только тех, у которых зарплата в рублях, 
  - сортировки по возрастанию или по убыванию зарплаты,
  - фильтрации вакансий по словам в описании, 
  - фильтрации вакансий по заданному диапазону зарплаты
* в модуле vacancies реализован класс для работы с вакансиями, в котором реализован 
  метод инициализации класса, магические методы сравнения и представления экземпляра класса
  в виде строки

* в модуле main реализована логика проекта: по условиям, 
  которые задает пользователь

## Установка:
1. Клонируйте репозиторий:
```git clone git@github.com:elenasyurtukova/Project_vacancy_search.git```

2. Установите библиотеки из pyproject.toml:
```poetry install```

## Тесты:
Каждый модуль проекта протестирован с помощью фреймворка pytest.
Чтобы запустить его (все тесты), выполните команду: ```pytest```.
Покрытие кода тестами составляет 81%
